# Weekly AI —— GitHub Trending AI 项目 Top 10

> **数据口径：** 本清单基于 GitHub Trending 的 **本周（weekly）** 页面于 **2026-09-13** 抓取到的项目，并筛选 AI、AI Agent、LLM、MCP 或与 AI 开发流程密切相关的条目。GitHub Trending 并没有提供“AI 分类的官方全站前十”接口；下面的编号是本次筛选后的展示顺序，并非全站精确排名。
>
> **视频说明：** 只有能够直接确认与项目对应的官方或热门视频才应当列入；本次抓取未逐项验证到可靠的直接视频地址，因此不附加 YouTube 链接，以避免误导。

## 本周趋势项目

## 1. ECC

**项目链接：** [affaan-m/ECC](https://github.com/affaan-m/ECC)

ECC 是一个面向 AI 编程 Agent 的性能优化与工程工作流系统。它将技能、记忆、安全约束和“先研究、后实现”的开发方法组织起来，可用于 Claude Code、Codex、OpenCode、Cursor 等不同智能体环境，帮助团队把复杂开发任务拆解为更可重复、可审查的流程。

## 2. Superpowers

**项目链接：** [obra/superpowers](https://github.com/obra/superpowers)

Superpowers 提供一套 Agentic Skills 框架与软件开发方法论，用于让编码智能体在需求澄清、规划、实现、测试和复盘等阶段采用明确的工作步骤。项目适合研究如何将通用大模型约束为更可靠的软件开发协作者，也可作为构建子智能体协作流程的参考。

## 3. MarkItDown

**项目链接：** [microsoft/markitdown](https://github.com/microsoft/markitdown)

MarkItDown 是微软开源的 Python 文件转换工具，可将 Office 文档、PDF 和其他常见文件转为 Markdown。对于 RAG、文档问答和 Agent 工作流，它可以作为数据摄取环节，把原始文件转换成更适合切分、检索和交给语言模型处理的文本格式。

## 4. Chrome DevTools MCP

**项目链接：** [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)

Chrome DevTools MCP 将 Chrome 开发者工具能力提供给支持 Model Context Protocol 的编码智能体。Agent 可借此检查网页、调试浏览器行为、读取控制台与网络相关信息，从而辅助前端开发、自动化测试和网页故障排查。它适合需要让代码助手“看见并理解”浏览器运行状态的场景。

## 5. Hyperframes

**项目链接：** [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)

Hyperframes 是一个面向 Agent 的视频渲染框架：开发者编写 HTML，再将其渲染为视频。项目结合网页技术、动画与视频处理能力，为 AI Agent 自动生成演示视频、动态内容或可编程视觉素材提供了基础。使用时仍应确保素材、人物形象和音视频内容均有合法授权。

## 6. Marketing Skills

**项目链接：** [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)

Marketing Skills 收集可供 Claude Code 及其他 AI Agent 使用的营销技能，覆盖转化率优化、文案、SEO、分析和增长工程等方向。它将营销任务转化为可复用的操作模板，帮助团队在内容制作、网站优化和数据分析时建立更一致的 Agent 工作流。

## 7. Context Mode

**项目链接：** [mksglu/context-mode](https://github.com/mksglu/context-mode)

Context Mode 专注于优化 AI 编程智能体的上下文窗口使用方式。项目通过隔离工具输出、持久化会话记忆，并结合 MCP 与 hooks 在多个平台之间路由上下文，目标是减少无关日志和重复信息占用，为长时间的软件开发任务保留更有价值的上下文。

## 8. OpenAI Skills

**项目链接：** [openai/skills](https://github.com/openai/skills)

OpenAI Skills 是面向 Codex 的技能目录。它提供可被编码智能体调用的任务能力描述与工作流入口，帮助使用者发现、组合或扩展适合特定开发任务的工具能力。该项目适合希望了解 Codex 技能生态，或为自己的自动化开发流程设计可复用能力单元的开发者。

## 9. WeKnora

**项目链接：** [Tencent/WeKnora](https://github.com/Tencent/WeKnora)

WeKnora 是腾讯开源的 LLM 知识平台，可把原始文档转化为可查询的 RAG 知识库、具备推理能力的 Agent 和可维护的 Wiki。它覆盖文档解析、检索、重排序、问答等知识服务链路，适合构建企业内部知识问答、文档检索与智能助手应用。

## 10. OpenMAIC

**项目链接：** [THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)

OpenMAIC（Open Multi-Agent Interactive Classroom）是一个多智能体互动课堂项目，旨在以多个 AI 角色构建沉浸式学习体验。项目可用于探索多 Agent 的角色分工、交流协作和教学反馈机制，也为构建互动式课程、模拟讨论或智能学习辅助工具提供了一个开源参考。
