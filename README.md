# Weekly AI — GitHub Top 10 AI Tools

> **Ranking basis:** GitHub repository stars at collection time (2026-09-06). This list is a dated snapshot from GitHub’s `topic:artificial-intelligence` search, sorted by stars—not a permanent leaderboard or editorial quality ranking.

## 1. AutoGPT
**Project:** [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)  
**YouTube:** [AutoGPT official/demo videos](https://www.youtube.com/results?search_query=AutoGPT+official+demo)

AutoGPT is an open-source framework for building and running AI agents. It helps people compose goal-oriented workflows in which models can reason through tasks, use tools, connect data sources and automate repeated work. It is aimed at developers and teams that want an extensible agent platform rather than a single chat interface.

## 2. prompts.chat
**Project:** [f/prompts.chat](https://github.com/f/prompts.chat)  
**YouTube:** [Awesome ChatGPT Prompts videos](https://www.youtube.com/results?search_query=Awesome+ChatGPT+Prompts+prompts.chat)

prompts.chat, formerly Awesome ChatGPT Prompts, is a community-maintained open-source prompt collection and discovery site. It provides reusable prompt patterns for writing, programming, marketing, learning and other tasks, and can be self-hosted for organizations that want greater privacy and control over their prompt library.

## 3. LLMs from Scratch
**Project:** [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch)  
**YouTube:** [Sebastian Raschka — LLMs from Scratch](https://www.youtube.com/results?search_query=Sebastian+Raschka+LLMs+from+Scratch)

LLMs from Scratch is an educational codebase for implementing a ChatGPT-like large language model in PyTorch, step by step. It covers tokenization, attention, transformer architecture, pretraining and fine-tuning, helping readers understand how modern language models work beneath high-level APIs.

## 4. Deep-Live-Cam
**Project:** [hacksider/Deep-Live-Cam](https://github.com/hacksider/Deep-Live-Cam)

Deep-Live-Cam is a real-time face-swapping and video manipulation project that can generate a swap from one image. It demonstrates computer-vision and generative-media workflows for local experimentation. Use it only with informed consent and clear disclosure: synthetic face content can create serious privacy, impersonation and misinformation harms.

## 5. claude-mem
**Project:** [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)  
**YouTube:** [claude-mem / Claude Code videos](https://www.youtube.com/results?search_query=claude-mem+Claude+Code)

claude-mem provides persistent, AI-compressed context across coding-agent sessions. It captures relevant activity, summarizes it and returns useful context in later sessions, reducing repeated explanation and lost project history. The project supports multiple agent environments, including Claude Code, Codex, Gemini, Copilot and OpenCode.

## 6. OpenHands
**Project:** [OpenHands/OpenHands](https://github.com/OpenHands/OpenHands)  
**YouTube:** [OpenHands official videos](https://www.youtube.com/results?search_query=OpenHands+AI+official+demo)

OpenHands is an open-source platform for AI-driven software development. Its agents can work on development tasks using code repositories, terminals and other tools, helping engineers delegate implementation, debugging and maintenance work. It targets developers who want transparent, extensible infrastructure for coding agents.

## 7. AI for Beginners
**Project:** [microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners)  
**YouTube:** [Microsoft AI for Beginners course](https://www.youtube.com/results?search_query=Microsoft+AI+for+Beginners+course)

Microsoft’s AI for Beginners is a structured introduction with 24 lessons across 12 weeks. It teaches machine learning, neural networks, computer vision, natural-language processing and responsible AI through explanations, examples, quizzes and practical exercises for people beginning their AI learning journey.

## 8. Strix
**Project:** [usestrix/strix](https://github.com/usestrix/strix)  
**YouTube:** [Strix AI security videos](https://www.youtube.com/results?search_query=usestrix+AI+penetration+testing)

Strix is an open-source AI-assisted penetration-testing tool focused on finding and helping fix application vulnerabilities. It supports security assessment workflows by combining agentic reasoning with testing tools and reporting. Use it only against systems you own or are explicitly authorized to assess; unauthorized testing can be illegal and disruptive.

## 9. MiniMind
**Project:** [jingyaogong/minimind](https://github.com/jingyaogong/minimind)  
**YouTube:** [MiniMind tutorial videos](https://www.youtube.com/results?search_query=jingyaogong+MiniMind+tutorial)

MiniMind is a compact learning project for training a small language model from scratch. Its examples walk through preparing data, defining a model, training and evaluation, making LLM mechanics approachable for students and practitioners who want hands-on experience without large-scale infrastructure.

## 10. Flowise
**Project:** [FlowiseAI/Flowise](https://github.com/FlowiseAI/Flowise)  
**YouTube:** [Flowise official YouTube](https://www.youtube.com/@FlowiseAI)

Flowise is a visual, low-code platform for building AI applications and agents. It lets users connect language models, retrieval systems, tools, APIs and memory through graphical flows, then deploy or integrate the resulting workflows. It is useful for rapid prototyping of chatbots, retrieval-augmented generation systems and custom agent applications.
